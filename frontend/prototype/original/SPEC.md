> 2026-09-23。本文是重建 `prototype/original-refined/` 的**唯一事实源**，token 的唯一实现是同目录的 `tokens.css`。

## 2. 统一 token 集

实现见 `tokens.css`，本节说明每个值从哪来、收拢了多少原值。页面 CSS 规则：

- 只引用变量，不写裸 hex、不写 `!important`，不用 `body .x`、`:is()` 抬优先级（原版三层覆盖的根因，dna-ops F1、brief T5）。
- `tokens.css` 的基础样式放在 `@layer base`，页面里未分层的规则自然覆盖它。
- 暗色由 `<html data-theme="dark|light">` 决定；没有属性时跟随系统。
- 带单位的数值、计数、金额、百分比、时长一律加 `.num`（Inter + 等宽 + 斜杠零）；单位包在 `.unit` 里。IP、端口、日期用正文字体 + `tabular-nums`（brief §4.11），不用等宽字体。

### 5.2 动效

只做短而轻的过渡，全部尊重 `prefers-reduced-motion`：

| 做 | 规格 |
|---|---|
| 分段滑块、页签指示条在项之间滑动 | `--dur-base` `--ease-out` |
| 弹层、菜单、tooltip 进入 | 上移 3 px + 淡入，`--dur-base`；离开 120 ms 淡出 |
| 抽屉、对话框、命令面板进入 | 抽屉右侧 24 px 位移 + 淡入；对话框、命令面板缩放 0.98 → 1 + 淡入；`--dur-panel`；遮罩淡入 `--dur-base` |
| 进度线、额度条宽度 | `--dur-bar` `--ease-std` |
| 折叠展开、侧栏分组 | 高度 + 箭头旋转，`--dur-base` |
| 状态变化 | 状态 pill 文字与底色交叉淡入 `--dur-base`；外圈 3 px 同色光环从 `-bg` 淡到透明一次，`--dur-flash` |

| 新增行、移除行 | 新增淡入 `--dur-base`；移除高度收起 `--dur-base` |

|---|---|
| 数字补间滚动 | 2 秒一次的实时值会一直在动，读不清（brief §5.2） |

| 每次数值更新时闪背景 | 41 张卡每 2 秒几十处变化，满屏闪 |

### 5.3 实时更新不抖动

数据由 `shared/live.js` 按真实节奏推送：Komari 主机指标 2 秒、线路机采集 10 秒、监控评估 10 秒、TCP 探测 30 秒、出口探测 300 秒、线路机面板 15 秒。规则：

1. **只改变化的文字**：订阅 `store.on('change', diff)`，用 `touched(diff, id, …)` 判断哪些格子受影响，用 `createPatcher().changed(key, text)` 只在格式化后的文字确实变化时写 DOM。不重绘整张卡、整张表。
2. **宽度固定**：所有数值 `tabular-nums`；3 位有效数字让 `812 Kbps` 和 `1.02 Mbps` 等宽；数值槽位设最小宽度（速率 9ch、字节 8ch、百分比 4ch、鲜度文字 10em），右对齐的列靠右锚定。小卡片信息格改左对齐（原版右对齐导致数值左右跳，dna-home J1）。
3. **行序节流**：按实时速率排序时，行序最多 5 秒变一次（`resortThrottleMs: 5000`），变化时用 FLIP 位移。**鼠标在网格或表格上、或键盘焦点在里面时，暂停重排**，离开后再应用，避免点错行。
4. **筛选成员变化**：节点因状态变化离开当前筛选时，先把这一行降到不透明度 0.5 并显示 12 `--fg-3` `已不符合筛选`，5 秒后收起；进入筛选的行淡入。
5. **tooltip 与弹层跟着数据走**：打开的 tooltip、今日流量弹层原地更新内容，不关闭、不跳位。
6. **状态变化要看得见**：pill 按 §5.2 闪一次外圈；KPI 副行的计数同步变化；需处理列表新增一行时淡入。
7. **新鲜度**：页头鲜度文字每秒更新（60 秒内），之后每 30 秒（`fmt.refreshEvery`）；全页共用一个计时器。
8. **标签页隐藏时暂停**（`live` 默认 `pauseWhenHidden`），回来时补一次快照，不逐帧追赶。

- 剪贴板被拒：tooltip `复制失败，已选中文字，请按 ⌘C`，并选中文字。

### 5.8 刷新与鲜度

- 自动刷新节奏见 §5.3；页头 ↻ 手动刷新当前页全部数据，图标旋转直到完成；成功不弹 toast（鲜度文字会变），失败弹不自动消失的 toast 并把鲜度变成“已断开”。
- 有对话框或输入焦点时，不刷新会影响正在编辑内容的数据（原运营页行为）；其它部分照常刷新。

### 5.9 触屏与只在 `title` 里的信息

- 所有只靠悬停的东西都有点击等价物：今日流量弹层点击固定；心跳格点按出 tooltip；口径说明用 ⓘ 弹层。
- 原版放在 `title` 里的口径（流量重复计量、到期时区、Xray 速率说明、带宽利用率、“已转发不代表目标网站已响应”）全部改成 ⓘ 弹层或可见副行。
- 触屏上可点目标至少 32×32（卡内 28 的按钮靠内边距扩大点击区）。

### 5.10 无障碍底线

- 文字对比度 ≥ 4.5:1（`-text` 状态字色、`--accent-soft-fg` 就是为此加深的）；非文字元素 ≥ 3:1。
- 颜色从不单独表达信息：pill 有文字，心跳格有 tooltip 和说明行，图表有图例文字和表格视图。
- 图标按钮都有 `aria-label`；分段、页签、菜单、对话框、抽屉用正确的 role 和键盘行为；抽屉和对话框困住焦点并在关闭后归还。

### 7.2 解析规则 `planOf(node)`（`original-refined/js/plans.js`）

1. `catalog.by_node_id[node.id]`；
2. 否则 `catalog.by_asset[node.name]`；
3. 否则查“推导别名表”：加载时遍历快照 41 个节点，把每个节点的（`provider` + 原始 `billing.plan`）映射到第 1 步得到的套餐 id，建一张内存表；流水线演示行（`团队1-37`…`44`，`provider` + `plan`）用它解析。这张表只在内存里用于匹配，**不显示**；
4. 仍然解析不到：`{ name: '未归类套餐', unresolved: true }`，显示 `--fg-3`，tooltip `套餐目录里没有这个节点`。

加载完成后做一次**就地替换**：每个节点写入 `n.plan_id`、`n.plan`（目录对象），并把 `n.billing.plan` 覆盖成规范名；`relays[].plan`、`onboarding.demo_batch.rows[].plan` 同样覆盖。这样 `shared/data.js` 里现成的套餐列、套餐 facet、`plan:` 搜索 token、搜索 haystack 自动用规范名，原始字符串从内存里消失，不可能被渲染出来。

**目录文件加载失败时**（兜底，现在用不到）：退回显示原始字符串，名称后加 IP 版本标记外形的 `原名` 标记（`--warn-text`），控制台警告一次；筛选和分组仍按原始字符串工作。
